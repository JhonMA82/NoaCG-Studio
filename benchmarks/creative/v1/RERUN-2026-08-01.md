  --coder-route=openrouter:qwen/qwen3-coder-next \

Each chunk needs its OWN `--out`: `pilot.json` is written at the END of a run, so a reused
directory loses the previous ledger while keeping its artifacts. The dev-bench server must be
running on this checkout's port and stopped before any e2e run reuses it.
