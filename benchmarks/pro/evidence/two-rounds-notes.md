# Two rounds, blind - notes

Written BEFORE running the gallery builder with --reveal, which writes
two-rounds-blind-key.html beside the page. Nothing on the page says which round an item came
from, and the frames are copied under their issued id so the file names do not say either.

Every item was composed by the SAME platform code from a design language bought in one of two
paid rounds, so the only thing separating the two halves of the page is the checkpoint that
wrote the language.

For each: does the palette read at broadcast distance? does the type carry a deliberate
hierarchy? do the accent and shape language look decided or defaulted? does the stress frame
still hold together?
