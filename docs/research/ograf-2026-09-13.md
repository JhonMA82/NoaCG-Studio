## Scope and reproducibility

Seven public repositories were cloned outside the NoaCG worktree and inspected at the revisions
listed in the main report. No upstream install scripts or browser applications were run. Reading
test source is identified as coverage intent. Only the pure probes below were executed, with
Node 24.13.0 and NoaCG's installed TypeScript transpiler stripping type-only imports. They do not
validate DOM, GSAP timing, network behaviour, independent rendering or hardware.

To refresh the evidence, clone each repository URL into a separate research directory, check out
the report's exact SHA, verify `git rev-parse HEAD`, then read the cited files. Source evidence
uses immutable blob links; issue and release status must be re-fetched before implementation.
Use new evidence rather than silently changing the old report's revision labels.
